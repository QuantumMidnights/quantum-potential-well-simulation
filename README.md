# MidnightQuantum

An educational website for exploring classical and introductory quantum potential-well models.

## Pages
- `index.html` — Quantum particle in a box simulation
- `classical.html` — Classical potential well simulation
- `doublewell.html` — Illustrative double-well potential and learning activity
- `comparison.html` — Classical vs quantum comparison and prediction activity
- `quiz.html` — Learning assessment and quiz tools

## Run locally
Open `index.html` in a modern browser. If you use VS Code, you can also run the folder with the Live Server extension. The site is static HTML/CSS/JavaScript and does not require a backend server for the simulations.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of the repository's `main` branch (keep `index.html` at the repository root).
2. On GitHub, open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Wait for the deployment to finish and open the Pages URL shown in Settings → Pages.
5. Test all navigation links and interactions on the published URL, not only in local files.

## Scientific scope and limitations
- The particle-in-a-box energy calculation uses dimensionless/atomic-style model units where indicated. Do not interpret those displayed model values as joules or electronvolts.
- The double-well page displays an illustrative potential profile; it does not calculate quantum eigenstates, tunnelling rates, or energy splitting.
- Assessment results and observations are browser-side features; export/download data as provided by the page. This static site does not provide a shared central database for multiple participants.
- Review assessment items with the project advisor before collecting research data. Do not claim learning gains until participant data have been collected and analyzed appropriately.
